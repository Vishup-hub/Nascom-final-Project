 # India’s Agricultural Crop Production Analysis (1997–2021)

## 📊 Project Overview

This project presents an interactive **Tableau dashboard** for analyzing agricultural crop production in India from **1997 to 2021**.

The project analyzes agricultural data across different **states, crops, seasons, cultivated areas, production, and yield** to identify important trends and patterns.

## 🎯 Objectives

- Analyze agricultural production in India.
- Compare production across different states.
- Analyze crop-wise cultivated area.
- Study year-wise production trends.
- Analyze agricultural yield trends.
- Compare production across different seasons.
- Identify leading states based on agricultural production.
- Present insights through an interactive Tableau dashboard.

## 📁 Dataset

**Dataset:** India’s Agricultural Crop Production Dataset

**Time Period:** 1997–2021
